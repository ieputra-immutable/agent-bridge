## Changes

- Show ordinary Claude peer messages with Claude's native cross-session
  presentation and the sender's session name or explicit registration alias.
  Remote names retain their machine qualifier.
- Replace repeated JSON envelopes and command instructions in Claude messages
  with the message text and a compact reference for acknowledgements and replies.
  Stable routing addresses remain separate from display names.
- Guide agents to keep shared-board entries brief, update existing entries, and
  leave detailed logs and explanations in their native sessions.

## Upgrade and compatibility

Run the installer again to update, then start or resume Claude sessions so they
receive the updated startup instructions. Managed upgrades preserve identity,
history and session grants. The MCP interface and board format are unchanged.

Claude's cross-session wrapper is internal and was checked against version
2.1.300. Automated protocol compatibility checks passed; a live native UI check
remains outstanding. Pairing and board control notices retain their existing
format. Codex message delivery is unchanged.

The client adapter refactor and OpenCode integration are planned separately and
are not included in this patch.
