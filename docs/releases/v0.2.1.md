## Changes

- Copy visible board text by dragging over it and releasing the mouse. Selection
  stays fixed while agents update the board, so the copied text matches what you
  selected.
- Press `m` outside the response editor to switch between board selection and
  the terminal's native mouse selection. Clipboard requests use OSC 52 and require
  support and permission from the terminal; selected text is limited to 64 KiB.
- Avoid redundant board redraws when content and status have not changed.

## Upgrade and compatibility

Run the installer again to update. Managed upgrades preserve identity, history and
session grants. This release does not change the MCP interface or board format.
See the [board guide](https://github.com/jasadams/agent-bridge/blob/v0.2.1/docs/board.md)
for selection, clipboard permissions and keyboard controls.
