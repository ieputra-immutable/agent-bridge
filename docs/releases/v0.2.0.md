## Changes

- Answer Markdown task checkboxes and marked multiline text fields in the terminal
  board, with revision checks and retained drafts when another writer changes it.
- Opt individual native sessions into board change notifications through MCP.
  Notifications coalesce after 3 quiet seconds with a 10-second coalescing cap;
  subscriptions are off by default and end with the session or broker restart.
- Read tables with visible horizontal row dividers, including wrapped cells.
- Select one peer explicitly when discovering remote agents through MCP. Existing
  per-session sharing tools let agents share their own selected session when asked;
  pairing still leaves current and future sessions private by default.
- Install immutable semantic-version releases for Linux and macOS. The release tag
  supplies the version reported by the binary, broker and MCP server.

## Upgrade and compatibility

Run the installer again to update. Managed upgrades preserve identity, history and
session grants, and retain a private backup. Reconnect the MCP server or restart
the agent client afterward to load the updated tools.

The `list_agents` MCP input changed: replace `{"remote":true}` with
`{"peer":"workstation"}`, using the paired peer's alias or ID. Omitting `peer`
lists only local sessions. The old `remote` argument is rejected by the new tool.

When using board subscriptions, pass your own registered session name in the
optional `agent` argument of `update_board` to suppress your own edit notices.
Unattributed changes notify every subscriber. Notifications prompt agents to read
the board; they do not make the document authenticated user approval.

The board remains local to one machine. See the documented security review and
remaining physical-network acceptance scope before depending on Internet routing
in an untested environment.
